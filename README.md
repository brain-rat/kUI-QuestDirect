# Forever Add-ons

Add-ons for **World of Warcraft: Forever** (client 1.60, Interface 16001): a quest tracker that plans each zone, and a flat, dark UI overhaul with bags, tooltips and a rare scanner.

**Project page:** https://brain-rat.github.io/kUI-QuestDirect/

| Folder | What it is |
|---|---|
| [`QuestDirect`](QuestDirect/README.md) | Quest tracker you can drag and scale. Click a quest and the TomTom arrow points at its next stop. Suggests quests to pick up nearby, plans the zone (which quest givers to visit, what to hand in and pick up, which objectives to do, where to go next), and has buttons for usable quest items. |
| [`kUI`](KUI/README.md) | One flat, dark style for the game's windows: player and target frames with cast bars, bags and bank with categories and a rarity glow on items, loot window, tooltips, square minimap, a rare and treasure scanner, and junk selling at vendors. |
| [`ForeverSync`](ForeverSync/README.md) | A small Windows program that downloads WoW Forever data from the ForeverDB API onto your PC, so it can be turned into data files for the add-ons. |
| [`tools`](tools) | Scripts that build the add-ons' Classic quest, rare and treasure data from the CMaNGOS Classic database. |

## Install

1. Download the latest release zip from the [Releases](../../releases) page.
2. Copy the `QuestDirect` and `kUI` folders into `World of Warcraft\_forever_\Interface\AddOns`.
3. Restart the game. Each add-on's read-me has its commands: `/qd` for QuestDirect, `/kui` for kUI.

QuestDirect works best with [TomTom](https://www.curseforge.com/wow/addons/tomtom) installed, for its on-screen arrow; without it, it uses the game's own map pin.

## Data

- **ForeverDB.** Forever's own quest, NPC and change data comes from the [ForeverDB API](https://foreverdb.net/developers), downloaded to your own PC with ForeverSync using your own API key. Wherever the add-ons show it, they credit **Data from [ForeverDB.net](https://foreverdb.net)** and keep each record's *Seen in WoW Forever* or *Classic data* label. The data isn't redistributed in this repository.
- **Classic data.** `QuestDirect/QuestData.lua` and `KUI/RareData.lua` are generated by the scripts in `tools` from the open-source [CMaNGOS Classic database](https://github.com/cmangos/classic-db) (GPL-2.0).
- **Your own play.** Quest givers you talk to, rares you see and things you loot are remembered in the add-ons' saved variables on your PC.

## Building

- **ForeverSync:** Go 1.24 or newer, standard library only. `cd ForeverSync && go test ./... && GOOS=windows GOARCH=amd64 go build -o ForeverSync.exe .`
- **Classic data:** clone `cmangos/classic-db`, then `python3 tools/quest_extract.py <ClassicDB_*.sql.gz> QuestDirect/QuestData.lua report.json` and `python3 tools/rare_extract.py <ClassicDB_*.sql.gz> KUI/RareData.lua`.

## Tests

`tests/` holds stubbed WoW environments that load each add-on outside the game and check its behaviour. They need `texlua` (from TeX Live) or any Lua 5.3+:

```
texlua tests/questdirect_test.lua QuestDirect
texlua tests/kui_test.lua KUI
```
