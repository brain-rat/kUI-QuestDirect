QuestDirect

quest tracker

A drag-and-scale quest tracker. Click a quest and the TomTom arrow points at its next stop: the objective area, the turn-in, or the game's own travel step when it's in another zone.

  • Suggests quests to pick up nearby, filtered by level, race, class and quest chains.
  • Plans the zone: which quest givers to visit in which order, what to hand in and pick up at each, which objectives to do, then where to head next.
  • Buttons for usable quest items, with a keybind.

ForeverDB use: quest givers, turn-ins and their map positions, chains and level ranges, so suggestions and plans use what's actually in Forever, including Forever's new quests.

kUI

UI overhaul

One flat, dark style for the game's own windows, with a shared font setting.

  • Player and target frames with matching cast bars.
  • Clean action bars, totems, menu and bag buttons, with size, layout, text and visibility you can set for each one.
  • Bags and bank with categories, every empty slot at the bottom, adjustable gaps, and a rarity outline and glow on each item.
  • Loot window, tooltips, and a square minimap.
  • Rare and treasure scanner: alerts, spawn points on the map, and spots you've looted before.

ForeverDB use: what's new or changed in Forever, so the rare scanner and lists can tell Forever-only content from Classic, shown with its Seen in WoW Forever or Classic data label.

ForeverSync

local data tool

A small Windows program that downloads ForeverDB data onto the player's own PC, where it's turned into data files for the add-ons above. Add-ons can't make web requests, so this is how the data reaches the game.

  • Paced to stay under 60 requests a minute and 10,000 a day.
  • Resumes where it stopped and only fetches what's new on later runs.
  • The API key stays on the player's PC and is only sent to foreverdb.net.
